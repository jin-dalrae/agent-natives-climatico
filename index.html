Onboard an agent in 4 steps

For a human setting up an agent's first interaction with Climatico. Total time: under a minute. Each step is a real call against the live Worker.

  1. 1. Discover the desk

    Read the agent card. It tells your agent what protocols, scopes, and ceilings are on offer.

    curl -sS "https://climatico.dalrae-jin-work.workers.dev/.well-known/agent-card.json" \
  | python3 -m json.tool | head -30
  2. 2. Mint a scoped token

    Scopes freeze at mint. Pick the smallest set your agent needs. For a tracer, that's climatico:read + climatico:transact (offset ceiling $50). For a buyer audit, climatico:read only.

    curl -sS -X POST "https://climatico.dalrae-jin-work.workers.dev/v1/credentials" \
  -H 'content-type: application/json' \
  -d '{"subject":"my-agent","scopes":["climatico:read","climatico:transact"]}'

    Save the returned token somewhere safe. Treat it like a hotel keycard: it's good for the doors it was minted for, and not upgradeable later.

  3. 3. File your first write

    Pick an intent. brief grounds a location's climate risk with real evidence (flags if it can't find any). fleet turns a spend spike into a kgCO2e number. greenwash gets flagged — and stored — so you can see the policy engine in action.

    # Set your token
export CLIMATICO_TOKEN="<paste token here>"

# File a brief (will commit, with evidence, or flag with a reason)
curl -sS -X POST "https://climatico.dalrae-jin-work.workers.dev/v1/actions" \
  -H "authorization: Bearer $CLIMATICO_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"intent":"brief","location":"Houston, TX"}'

# Try a fleet run (ingest → audit → settle, all in one call)
curl -sS -X POST "https://climatico.dalrae-jin-work.workers.dev/v1/fleet/run" \
  -H "authorization: Bearer $CLIMATICO_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"source":"cloud","location":"SJC","spendUsd":420,"monthlyBudgetKg":50,"monthToDateKg":40}'

# See the policy engine flag a greenwash claim (and store the flag)
curl -sS -X POST "https://climatico.dalrae-jin-work.workers.dev/v1/actions" \
  -H "authorization: Bearer $CLIMATICO_TOKEN" \
  -H 'content-type: application/json' \
  -d '{"intent":"greenwash","location":"Orepath Global Chain"}'
  4. 4. Verify the receipt

    Every write — committed or flagged — returns a receipt and is durably stored. List yours:

    curl -sS "https://climatico.dalrae-jin-work.workers.dev/v1/receipts?subject=my-agent" \
  -H "authorization: Bearer $CLIMATICO_TOKEN" | python3 -m json.tool

    That's the loop. Your agent can now file, get flagged, and verify — all with the same notebook under it.

Use it from your laptop

A real climatico CLI lives in climatico/climatico.sh. For an Orepath-shaped setup, see SETUP.md — covers subject prefix, token persistence, and the connect <folder> --dry-run folder-scan that auto-assesses your work folder without sending any file contents. 

# Quick demo
./climatico/climatico.sh discover
./climatico/climatico.sh mint orepath-supply-tracer
./climatico/climatico.sh fleet SJC 420
./climatico/climatico.sh report
./climatico/climatico.sh receipts
