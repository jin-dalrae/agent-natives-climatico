1. Navigate to your repository on GitHub.com
2. Click the "Settings" tab in the top navigation bar
3. In the left sidebar, scroll down to the "Code and automation" section and click "Pages"
4. Under "Build and deployment", make sure "Source" is set to "Deploy from a branch"
5. In the "Branch" dropdown, select "main" (or whichever branch contains your website files)
6. Under "Folder", leave it as "/ (root)" unless your site files are in a specific folder (like `/docs`)
7. Click "Save" to enable GitHub Pages

GitHub will begin building your site. The URL will be displayed at the top of the page shortly after.

Note: It may take up to 10 minutes for your site to be published.

URL format: `https://<your-username>.github.io/<repository-name>/`
